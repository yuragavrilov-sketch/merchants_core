# Expanded test export

[`merchants-core-test-data.zip`](./merchants-core-test-data.zip) contains a
sanitized export of the full merchant-core test dataset captured from Oracle:

- 1,187 merchants;
- 36,520 merchant configuration rows;
- 15,024 terminal rows;
- CSV files and an equivalent SQL insert script.

The archive contains no raw credentials, personal names, bank accounts, tax
identifiers, endpoint credentials, or production URLs. See the README inside
the archive for loading instructions and the replacement rules.
